# 数据与业务契约

wall 为同堂相对秒，content 为媒体位置，重复播放可使两者不同。responded=null 且 delivered=false 表示没送达，不是未回应。inclusion_probability 为该次提问的抽样机会。集体播放 roster 不等于全部实际到场者，min/max_people 为签到范围。

## 数据集合

- `players`：主键为 `stream`；必填字段 `stream, device, course, duration, wall_start, content_start, network`，当前 26 条。
- `heartbeats`：主键为 `heartbeat`；必填字段 `heartbeat, stream, wall, content`，当前 365 条。
- `probes`：主键为 `probe`；必填字段 `probe, stream, wall, inclusion_probability, delivered, stratum`，当前 52 条。
- `group_sessions`：主键为 `stream`；必填字段 `stream, min_people, max_people, roster`，当前 1 条。
- `courses`：主键为 `course`；必填字段 `course, topic, duration`，当前 3 条。
- `sampling`：主键为 `design`；必填字段 `design, stratum, probability`，当前 2 条。

集合中的主键不得重复；schema 的 foreign 引用须指向已存在的记录。可空字段保留 null 的业务含义，不自动补零。

## 查询与材料

GET 查询使用 UTF-8 JSON，错误参数返回 400，不存在的接口返回 404。重复的单值参数视为无效。summary 与 HTTP 调用同一组只读计算，材料包含数据内容指纹和生成时间，便于核对输入。当前输出描述已有数据，不承诺未实现的推断结论。

## 现有办理协作

sampling_plan.prepare 接受人工设备清单与计划抽样机会；probe_delivery.deliver 执行每人打扰上限、可跳过重复设备；probe_receipts.record 保留真实回应。当前只存计划机会，尚未据实际投放机制修正估计。

每个操作在本地业务日志的事务中更新；失败不提交半条办理记录。已有人工流程可以继续使用，新增分析尚未作为这些操作的有效依据。接口传入业务标识，未知标识或不满足条件返回错误，不自动补建对象。
